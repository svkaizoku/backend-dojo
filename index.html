The problem

Interview prep shouldn't be only puzzles.

Backend interviews test how you review code, build components, fix bugs, explain trade-offs and design services. Most prep only covers algorithms.

✕Usual prep

  • Algorithm puzzles that look nothing like production code
  • Bug lists in blog posts, with no way to test yourself
  • System design videos you only watch
  • Another paid subscription for AI feedback
→

✓Backend Dojo

  • Realistic Spring, Kafka, Redis and SQL code for every round
  • Code that compiles and runs against tests from your browser
  • An answer key for everything: what matters, why, and the fix
  • AI grading and Ask AI on the account you already have

How it works

Practise, check, learn.

No account, no install. Your progress stays in your browser.

  1. 01

    Pick an exercise

    Choose a mode, a topic and a level, in Java or Kotlin.

  2. 02

    Do the work

    Write your review or answer, or code in the editor and run the tests.

  3. 03

    Grade it

    Your AI compares your work with the answer key. A free keyword check works without AI.

  4. 04

    Study the key

    See every point with why it matters, the fix, a reference solution and further reading.

Bring your own AI

Your AI account, your data.

Grading and Ask AI run on an AI account you connect, so you pay your provider directly and the site needs no server.

OR

OpenRouter

Sign in with one click. One account reaches Claude, GPT, Gemini and more.

A

Anthropic

Paste an API key to use Claude. Claude.ai subscriptions can't be used by other apps.

O

OpenAI and Gemini

Paste an API key from the OpenAI platform or Google AI Studio.

Key stays in your browser

Kept for the current tab by default. Disconnect deletes it.

No server in between

Requests go straight from your browser to the provider you chose.

Locked-down pages

The site can only call the AI providers and code runners, and loads no third-party scripts.

Where code runs

Kotlin runs on JetBrains' compiler service; Java on Judge0, free or with your own key.

Contribute
